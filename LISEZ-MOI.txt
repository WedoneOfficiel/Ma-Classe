MaClasse V24.1 — intégration d’ArIA Core 2.0
================================================

Cette archive conserve les fonctions de MaClasse V24.0 et ajoute ArIA Core 2.0 comme routeur d’intentions local. Le moteur conversationnel V24.0 reste séparé ; MaClasse garde la responsabilité de vérifier les données et d’exécuter les actions.

INSTALLATION RAPIDE (Mac Apple Silicon)
1. Décompressez l’archive dans un nouveau dossier, sans écraser V24.0.
2. Ouvrez le Terminal dans ce dossier et exécutez :
   chmod +x Lancer-MaClasse.command Arret-ArIA.command models/*.command
   ./models/install_aria_core_2.command
   ./Lancer-MaClasse.command
3. Vérifiez le routeur dans le navigateur : http://127.0.0.1:8081/health
4. Le modèle de base Qwen3.5-2B-MLX-4bit est téléchargé au premier routage. La première requête peut être lente.

Le dossier data contient les données de cette archive (vide par défaut). Pour conserver les données de votre installation précédente, copiez uniquement vos données après avoir fermé MaClasse et créé une sauvegarde. Ne remplacez jamais une base existante sans sauvegarde.

Arrêt : exécutez Arret-ArIA.command.
Voir NOTES_V24_1.txt et models/aria-core-2.0-router/README.md pour les détails.

MaClasse V21.08 — améliorations de la messagerie et des périodes de bulletins
=======================================================

CONCEPTION

La messagerie a été reconstruite autour de messages individuels. L’interface est organisée en trois panneaux : dossiers, liste des messages, lecture. Le style reprend les variables visuelles de MaClasse.

Schéma de données :

  Utilisateur
      │
      ├── État de boîte par message : dossier / lu / favori
      │
  Message indépendant
      ├── id, threadId, inReplyTo, forwardedFrom
      ├── expéditeur, À, CC, CCI
      ├── objet, contenu, date, pièces jointes
      └── citation du message transféré (sans recopier les CCI)

  Fil (vue calculée, pas un objet contenant tous les messages)
      └── regroupe les messages partageant threadId

Cycle de vie :
- Nouveau message : crée un message indépendant, un état « Envoyés » pour l’auteur et un état « Réception » pour chaque destinataire.
- Répondre : crée un nouvel échange indépendant contenant une copie du message d’origine et la réponse ; le message source reste intact et la copie retire les CCI. Le nouvel échange conserve une référence vers la source.
- Répondre à tous : propose l’expéditeur et les destinataires À/CC du message ciblé ; les CCI ne sont jamais révélées ni reprises. Les destinataires sont filtrés selon les accès du compte.
- Transférer : crée un nouvel échange, cite le contenu source et conserve les pièces jointes ; les CCI de la source ne sont pas copiées.
- Lire, favori, archiver et supprimer : l’état est indépendant pour chaque utilisateur. Archiver/supprimer un message agit sur les messages visibles du fil pour cet utilisateur.
- Recherche : limitée aux messages auxquels le compte courant a accès.

ATTENTION — RÉINITIALISATION DE LA MESSAGERIE

Comme demandé, il n’y a pas de migration de l’ancien modèle. Le stockage est recréé avec le schéma V2 à la première ouverture de la messagerie. À la première ouverture de la nouvelle messagerie, les anciennes conversations, messages et dossiers de messagerie sont supprimés des données actives ; les autres données MaClasse sont conservées. Faites une sauvegarde complète avant cette première ouverture si vous souhaitez pouvoir retrouver l’ancien état. Cette suppression est déclenchée à l’ouverture de la messagerie, pas à l’ouverture du tableau de bord.

FONCTIONNALITÉS INCLUSES
- Réception, non lus, envoyés, brouillons persistants, favoris, archives, corbeille et dossiers personnels.
- Recherche, lecture par fil, réponse, réponse à tous et transfert.
- Destinataires élève/enseignant, CC/CCI côté enseignant.
- Pièces jointes à l’envoi, sauvegardées dans les brouillons et conservées lors des transferts.
- Interface trois panneaux, navigation responsive et actions adaptées au compte.

LIMITES CONNUES DE CETTE LIVRAISON
- Les brouillons persistants et les dossiers personnalisés ne sont pas encore intégrés à ce nouveau modèle.
- L’interface est une messagerie interne MaClasse, pas une connexion à Gmail/Outlook ou à des adresses externes.
- Une recette visuelle manuelle complète dans Firefox/macOS reste à effectuer.

INSTALLATION
1. Fermez MaClasse.
2. Faites une copie de sauvegarde du dossier de données et de l’ancienne version.
3. Décompressez MaClasse_V21_03.zip dans un nouveau dossier.
4. Lancez MaClasse comme d’habitude.
5. Ouvrez la messagerie pour activer le nouveau modèle. Cette première ouverture efface l’ancienne messagerie des données actives, conformément à votre demande.

Important — anciens moteurs IA :
Les modèles et adaptateurs fournis dans les anciennes versions ne sont plus inclus.
Les versions précédentes pouvaient télécharger des modèles dans le cache personnel
de macOS (en dehors du dossier MaClasse). Le présent paquet ne supprime pas ces
caches personnels automatiquement, afin de ne pas effacer d'autres modèles ou
données d'autres applications. Le lanceur V24.2 arrête uniquement les anciens
processus ArIA MaClasse dont il retrouve les fichiers PID connus.
