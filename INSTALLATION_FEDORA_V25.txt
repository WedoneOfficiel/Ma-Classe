MaClasse V25.0.7 — installation locale sur Fedora
==================================================

Cette procédure cible le PC Linux qui héberge MaClasse.
Le serveur écoute exclusivement sur 127.0.0.1 : il reste inaccessible
depuis les autres appareils du réseau tant que l'authentification,
HTTPS et les contrôles d'accès réseau ne sont pas validés.

PRÉREQUIS
- Fedora avec Python 3.
- Un compte utilisateur autorisé à écrire dans le dossier MaClasse.
- Connexion Internet lors de l'installation des dépendances.

INSTALLATION
1. Place le dossier MaClasse dans ton dossier personnel (par exemple ~/MaClasse).
2. Ouvre un terminal dans ce dossier.
3. Si Python 3 ou pip manque : sudo dnf install python3 python3-pip
4. Rends les scripts exécutables :
   chmod +x Installer-MaClasse-Fedora.sh Lancer-MaClasse-Fedora.sh
5. Installe les dépendances :
   ./Installer-MaClasse-Fedora.sh
6. Démarre MaClasse :
   ./Lancer-MaClasse-Fedora.sh
7. Dans Firefox sur ce même PC, ouvre :
   http://127.0.0.1:8765

COMPTES INITIAUX
- Direction : admin / admin
- Professeur : enseignant / enseignant

Le changement du mot de passe initial est obligatoire à la première
connexion. Choisis un mot de passe personnel d'au moins 12 caractères.

DONNÉES ET SAUVEGARDES
- Base : data/maclasse.json
- Fichiers : data/uploads/
- Sauvegardes : data/backups/

Ne place pas ces données dans un dossier synchronisé publiquement.
Avant une mise à jour, arrête MaClasse et copie le dossier data complet.
Ne supprime jamais .venv pour mettre à jour le code ; l'environnement peut
être recréé si nécessaire avec le script d'installation.

UTILISATION SIMULTANÉE
Le serveur MaClasse est léger et reste dans un terminal. Firefox et Spotify
peuvent être lancés en parallèle, mais la fluidité réelle dépend du processeur,
de la mémoire disponible et de la version Fedora. Le PC cible (4 Go de RAM)
doit encore faire l'objet d'un essai réel avec les trois applications ouvertes.

SÉCURITÉ — LIMITES ACTUELLES
- Pas de connexion depuis le Wi-Fi ou un autre appareil.
- Pas de redirection de port sur la box.
- Ne change pas MACLASSE_HOST.
- Les comptes élèves ne sont pas encore activés.
- HTTPS/TLS et la recette complète Firefox restent à effectuer.

ARRÊT
Dans le terminal où MaClasse tourne, appuie sur Ctrl+C.
