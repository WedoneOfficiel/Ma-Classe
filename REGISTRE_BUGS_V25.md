# Registre des bugs — MaClasse V25

**Document de référence des anomalies signalées, des correctifs et des recettes restantes.**  
Version de référence : `V25.1.1`, publiée le 26 novembre 2026 ([release v25.1.1](https://github.com/WedoneOfficiel/Ma-Classe/releases/tag/v25.1.1)). Les PR #13 à #19 ont intégré la stabilisation V25.1.0, les correctifs HTTPS/macOS, le rollback et le gestionnaire de mise à jour.
**Dernière synchronisation :** 27 novembre 2026 — candidat V25.2.0 sur la PR #20. La tête actuelle `829fd19181994648ac38f3dcb9dfebd80c77ca31` a passé le workflow [run 46008158550](https://github.com/WedoneOfficiel/Ma-Classe/actions/runs/46008158550), Linux, macOS Apple Silicon/`launchd` et Firefox réel, **3/3 jobs réussis**. L'arbre contient 113 fichiers de tests (68 JavaScript, 45 Python) et 860 invariants intermodules. Le paquet de release vérifie le runtime, tous les lanceurs racine, la clé publique Ed25519 et l'exclusion des données locales, bases, certificats et clés privées. Les tests de sauvegarde vérifient la création atomique de l'archive complète, la restauration de pièces jointes très compressibles, les limites d'entrée et le refus de chemins ambigus. Les métadonnées restent alignées sur V25.2.0 ; aucun changement de schéma ni migration n'est prévu. Le mode TLS public DNS facultatif n'est pas configuré sur le réseau cible ; la recette physique, les vrais comptes et les appareils clients restent à effectuer. Aucun statut du registre n'est passé à « Corrigé » sur la seule base de CI.

## Règles de suivi

- **Détecté** : le problème est identifié, mais aucun correctif n'est encore engagé.
- **En cours de résolution** : diagnostic et/ou correctif en cours.
- **Supposé résolu** : le correctif paraît techniquement bon et les tests disponibles passent, mais l'utilisateur ne l'a pas encore confirmé en conditions réelles.
- **Corrigé** : uniquement lorsque l'utilisateur confirme explicitement que le problème a disparu lors de ses essais. L'assistant ne peut jamais attribuer seul cet état.
- Un test automatisé réussi ne suffit pas à passer un bug en « Corrigé ».
- Les problèmes signalés par l'utilisateur et les défauts supplémentaires trouvés pendant l'audit sont conservés séparément.
- Chaque anomalie conserve son identifiant dans le journal technique `SUIVI_CORRECTIFS_V25.md`.
